## 3. 真实数据源方案（可直接落地）

- **国家统计局新版接口**：`https://data.stats.gov.cn/dg/website/publicrelease/web/external`，无需鉴权；分省月度/季度/年度社零、CPI。指标按 UUID（`cid`）+ 时间分片（2016–2020 / 2021–2025 / 2026– 至今）分段请求后按时间拼接；`cid` 应从目录树接口动态发现，硬编码会在跨年失效。
- **高德 Web 服务 POI**：个人认证约 3000 次/日，单次最多 200 条。必须按「矩形/多边形网格切分 + POI 小类码（如 050100 而非笼统 050000）」降低单次返回量，否则触顶漏数。
- **百度地图 POI**：`industry_type` 可直接过滤 `cater`（餐饮）/ `life`（生活娱乐），部分含评分、营业时间。
- **合规边界**：只采公开聚合字段（评分、评论数、营业状态），不抓用户原文；遵守 `robots.txt` 与限速；个人/学术用途也需限流。
- **可选**：企查查/天眼查（需 Token，免费额度有限），仅用于「连锁化率」等特定指标。

## 4. 从零复现步骤（可执行）

1. `python -m venv .venv`（Python 3.10.9 x64）
2. `.venv\Scripts\activate` → `pip install -r requirements.txt`
3. `python main.py`；窗口不显示时用 `热力图开发问题报告.md` P001 的 `SetForegroundWindow` 脚本
4. **验收七步**：窗口打开 → `pywebviewready` 触发 → `data/*.db` 生成 → 默认管理员 `admin/admin123456` 可登录 → 导入一条 JSON → 跑通「清洗融合」→ 跑通 RFM 或预测 → 前端能取到结果
5. 平台依赖：Windows 需 **WebView2 Runtime**；`pywebview==6.2.1` + `pythonnet==3.1.0` 是桌面壳硬依赖
