## 4. 三条硬提醒

1. **开题报告里写的技术路线，必须和最终做出来的一致**。答辩老师会拿开题报告对照论文，写“用 Spark 做实时分析”结果没做，就是硬伤。**开题报告的技术路线部分，逐字照抄 `docs/ROADMAP.md` §0.5 那张表**（单机桌面 / Pandas 主引擎 / Spark 仅对照 / SQLite+MySQL 双后端 / 四个数据源）。
2. **中期检查表填“已完成”的东西必须真能演示**。W3 那次检查前，S2-1a/S2-1b/S2-2 必须真跑通一次并留截图。
3. **论文里的每个数字都要有出处**（行数、耗时、通过率）。凡是拍脑袋写的，答辩现场一问就崩；凡是脚本跑出来的，直接说“这个数字来自 `scripts/xxx.py` 的输出”。
