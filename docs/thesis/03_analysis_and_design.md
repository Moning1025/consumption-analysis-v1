### 3.3.1 模块1（数据预处理）设计

TODO（约 500 字 + 2 张流程图，**这是全文技术核心**）
- **接入子流程**：本地文件（CSV/Excel）/ 高德 POI / 统计局接口 → 适配器统一成 `list[dict]` → 落 `ingestion_row` → 校验 → 进 `consumption_record`。异常：文件编码、字段缺失、接口配额超限。
- **清洗子流程**：7 阶段流水线（接入 → 去重 → 缺失值 → 对齐 → 融合 → 质量校验 → 结果输出），每阶段写清：输入 → 规则 → 输出 → 丢弃原因编码。
- 去重策略：先归一化（全半角/空格/繁简/符号）再比对，大表用分桶降低比对量。
- 缺失值策略：按字段分级（关键字段缺失丢弃、非关键字段补默认值并打标）。
- **执行证据**：每阶段写 `job_event.payload_json = {输入行数, 输出行数, 丢弃行数, 丢弃原因分布, 耗时ms}`。
