# 参考文献

> 要求：**10~20 篇**，正文必须实际引用，按正文引用顺序编号，著录格式按 **GB 3469**。
> 规则：宁可少而真（都是你真读过的），不要多而假（编造文献在答辩现场一问就露）。
> 建议配比：中文期刊/学位论文 6~8 篇 + 外文 2~3 篇 + 官方文档/技术标准 2~3 篇。

## 待填清单（按正文首次引用顺序编号）

1. TODO 数据融合 / 实体对齐方向的中文期刊论文（支撑 1.2 与 3.3.3）
2. TODO 消费数据分析或商业智能应用的学位论文（找本校往届最稳）
3. TODO 数据清洗质量相关论文（支撑 3.3.2）
4. TODO Pandas 或 Python 数据分析教材
5. TODO 数据库系统（SQLite/MySQL）教材或官方手册
6. TODO 可视化相关（ECharts 官方文档或中文专著）
7. TODO 英文文献 1（S7 如果需要对比 Spark，就引 Spark 论文/官方文档）
8. TODO 国家统计局或高德开放平台官方文档（电子资源按 GB 3469 著录需注明访问日期）

## 著录格式示例（GB 3469 / GB/T 7714 顺序编码制）

- 期刊：`[1] 作者. 题名[J]. 刊名, 年, 卷(期): 起-止页.`
- 学位论文：`[2] 作者. 题名[D]. 城市: 学校名, 年.`
- 专著：`[3] 作者. 书名[M]. 版次. 出版地: 出版社, 年: 起-止页.`
- 电子资源：`[4] 发布者. 题名[EB/OL]. (发布日期)[访问日期]. URL.`
