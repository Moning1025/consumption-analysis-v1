# Triage 标签

技能用五个规范的 triage 角色来思考；本文件把角色映射到本仓库 issue tracker 里实际使用的标签字符串。本仓库沿用默认五角色，不做别名。

| 技能里的角色（mattpocock/skills） | 本仓库实际标签      | 含义                                 |
| --------------------------------- | ------------------- | ------------------------------------ |
| `needs-triage`                    | `needs-triage`      | 维护者需要评估这张 issue             |
| `needs-info`                      | `needs-info`        | 等待报告人补充信息                   |
| `ready-for-agent`                 | `ready-for-agent`   | 规格已完整，可以交给 AFK agent       |
| `ready-for-human`                 | `ready-for-human`   | 需要人来实现                         |
| `wontfix`                         | `wontfix`           | 不会处理                             |

当某个技能提到某个角色（例如「打上 AFK-ready 的 triage 标签」）时，用表格右列对应的标签字符串。

只在需要给某个词汇表改动时，才改右列；本仓库当前不需要。
