## 四、已知未覆盖 / 待人工复验项

1. **桌面 GUI 自动化**：pywebview 窗口内鼠标点击/拖拽无自动化执行，以上"待人工"项需你重启 `python main.py` 后逐条点击验证。
2. **新建记录弹窗字段**：当前弹窗字段为通用表单（title/subtitle/status/progress/import_time/operator/term_count/meta_primary/meta_secondary），与说明书截图（文件名/来源类型/存储路径/状态/进度）不一致，需按说明书调整。
3. **查看详情弹窗**：点击后曾报"弹窗元素不存在"或加载错误，需人工复验。
4. **执行任务按钮**：后端需 `pipeline_id` 参数，前端未传，需补默认值。
5. **清洗融合真实性**：当前状态推进为定时模拟（1s/3s/6s），未真实解析文件内容写宽表；下游 RFM/情感/预测读到的是种子数据而非导入文件的真实聚合。
6. **下游模块渲染**：第4~10章页面的图表/列表在导入真实数据后的渲染效果未做端到端验证。
7. **首页日志输出区**：已从原始 JSON 堆叠改为摘要式（时间戳+级别+关键字段），需人工确认可读性。
